# First Run Checklist

Use this checklist immediately after installation.

1. Launch Audio Visualizer.
2. Confirm the tray icon appears near the Windows clock.
3. Play audio from any app.
4. Verify the taskbar visualizer animates.
5. Right-click tray icon → **Settings...** to adjust mode, theme, sensitivity.

## Common Controls

- **Settings...** — opens window for mode, theme, sensitivity, width, and effects
- **Show/Hide Visualizer** — toggles visibility (text changes based on state)
- **Check for updates** — checks for a new version; becomes **Restart to update** after a verified download
- **Quit** — exits the application

## If Something Looks Wrong

- No tray icon: check the **^** hidden-icons area next to the clock; drag the cyan equalizer into the visible tray. Close older running copies and relaunch the updated app if it is still missing.
- No animation: ensure your system output device is active and audio is playing.
- Unexpected behavior: see [../help/TROUBLESHOOTING.md](../help/TROUBLESHOOTING.md).

See [Updating Audio Visualizer](UPDATES.md) for automatic downloads, restart,
portable upgrades, and recovery.
